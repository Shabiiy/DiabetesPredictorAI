DiabetesPredictorAI

A full-stack, machine-learning–based diabetes risk prediction system built with React, Vite, Express, TypeScript, and a trained ML classification model. This project demonstrates end-to-end applied AI — from preprocessing and model inference to frontend UI and backend APIs.

🔍 Overview

DiabetesPredictorAI allows users to input health metrics and receive an estimated diabetes risk generated by an ML model.
The system includes:

Trained ML model for prediction

Node.js + Express backend for real-time inference

Modern React (Vite) frontend for user input and results

Clean architecture with separate client/server structure

🚀 Features

Diabetes risk prediction using ML

REST API for inference

Responsive UI (React + Tailwind)

Real-time prediction results

Input validation & helpful interpretation

Production-ready setup (Vercel + Render)

🛠️ Running the Project
1. Install dependencies
npm install
cd client && npm install
cd ../server && npm install

2. Start backend
cd server
npm run dev


Backend: http://localhost:5000

3. Start frontend
cd client
npm run dev


Frontend: http://localhost:5173

🌐 Deployment
Frontend (Vercel)

Root directory: client

Build command: npm run build

Output: dist

Backend (Render)

Root directory: server

Start command: npm run start or node dist/index.js

Client Environment Variable
VITE_API_BASE=<your backend URL>
